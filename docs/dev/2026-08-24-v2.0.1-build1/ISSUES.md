### 6. #19 — 为什么没有其他模型了
- **动作**：`Close as completed`
- **回复文案**：
> WitNote 支持通过 **Cloud API** 连接 DeepSeek 等任意 OpenAI 兼容大模型：
> 1. 打开 **设置 → AI 引擎 → Cloud API**
> 2. API URL 填写：`https://api.deepseek.com/v1`
> 3. 填写您的 DeepSeek API Key，模型名填 `deepseek-chat` 或 `deepseek-reasoner` 即可。

---

### 7. #10 — 外部ollama模型调用问题
- **动作**：`Close as completed`
- **回复文案**：
> 跨局域网连接其他机器的 Ollama 请按如下配置：
> 1. 在运行 Ollama 的 Linux 机器上设置环境变量：`OLLAMA_HOST=0.0.0.0 ollama serve`
> 2. 在 WitNote **设置 → AI 引擎 → Ollama** 中，将地址改为 Linux 机器的局域网 IP（例如 `http://192.168.1.x:11434`）。

---

### 8. #8 — WebLLM引擎是否可以下载使用
- **动作**：`Close as not planned` / `Close`
- **回复文案**：
> WebLLM 内置模型由于效果和硬件限制仅作实验性支持，推荐直接使用 **Ollama**（本地强模型）或 **Cloud API**（接入 DeepSeek/GPT），体验更流畅稳定。后续版本也将进一步聚焦 Ollama 和 API 接入。

---

### 9. #7 — MacOS系统满足要求却无法安装
- **动作**：`Close`

> WitNote macOS 版本仅支持 **Apple Silicon（M1/M2/M3/M4 系列芯片）**，不兼容旧款 Intel 处理器 Mac。请在「关于本机」中确认芯片类型。
