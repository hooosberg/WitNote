## 📝 新开发周期建立规范

在开启下一次大版本或专项迭代时，请按如下步骤新建：

1. **命名规则**：`YYYY-MM-DD-v版本号-主题`（例如：`2026-09-01-v1.4.1-latex-enhancement`）
2. **周期内推荐包含文档**：
   - `ROADMAP.md`：本周期目标、技术方案设计与任务拆解
   - `SECURITY.md`：若涉及漏洞修复，记录攻击向量与 diff
   - `ISSUES_LOG.md`：本周期响应的社区反馈与关闭记录
3. **在根目录 `docs/dev/README.md`** 添加一条周期索引记录。
